# 05 — Criação de animais

**Animal bem cuidado é comida, adubo, força e segurança que se renovam todo ano.** Comece
pequeno (galinhas), aprenda com os erros baratos e só aumente a criação quando sobrar água e
comida para atravessar a pior seca.
